    1. Right-click in the folder (empty space)
    2. Select "Open PowerShell window here"
    3. Paste: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
    4. Press Enter
    5. Paste: .\RUN.ps1
    6. Press Enter

    1. Open PowerShell in the project folder
    2. Paste: streamlit run app.py --server.port 8502
    3. Press Enter

    1. Right-click RUN.bat
    2. Select "Edit"
    3. Find: streamlit run app.py
    4. Change to: streamlit run app.py --server.port 8502
    5. Save
